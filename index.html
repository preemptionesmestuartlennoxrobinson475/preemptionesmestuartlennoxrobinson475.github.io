🎨 Mosaic-Field-Generative-Art - Create Beautiful Generative Art Patterns

Mosaic Field is a seed-based generative art system that turns simple grids into intricate textile-inspired compositions. Using an 80 × 80 grid, it fills each cell with waves, checkers, blobs, rings, dots, or swirls, then masks the result into a shape and draws every tile as a square, circle, or rotated element. Every result is reproducible from its seed, making it a practical catalogue of computational textile designs.

Built with HTML, CSS, JavaScript, and p5.js, Mosaic Field runs entirely in your web browser. You do not need to install any programming tools. Whether you are exploring pattern design, procedural generation, or creative coding art, Mosaic Field gives you a direct way to produce rich, repeatable visual compositions.

🧩 What You Can Create

Mosaic Field is a flexible generative art toolkit. The system combines several layers of variation to produce a wide range of computational textile compositions.

  • Seed-based reproducibility: Every composition is driven by a seed value. Enter the same seed to recreate the exact same artwork at any time.
  • 80 × 80 grid: The field is divided into 6,400 individual cells. Each cell can be filled with a pattern and drawn as a tile.
  • Pattern fills: Choose from waves, checkers, blobs, rings, dots, or swirls. Each pattern responds to threshold values that determine which cells are filled and which remain empty.
  • Tile shapes: Draw the grid using squares, circles, or rotated tiles. Switching shapes changes the visual rhythm of the entire composition.
  • Shape masks: Apply a mask to confine the pattern into a specific silhouette. This creates a focal shape within the larger field.
  • Textile-inspired output: The results resemble woven fabrics, quilted panels, and patterned cloth. The system is a catalogue of repeatable computational textile designs.

🎛️ How to Use Mosaic Field

The interface is organized around a small set of controls. You do not need to write any code to use the application.

  1. Set a seed. Enter a number in the seed field. This number determines the random values used to generate the composition. Change the seed to explore new variations.
  2. Choose a pattern. Select from waves, checkers, blobs, rings, dots, or swirls. Each pattern applies a different thresholding rule to the grid.
  3. Pick a tile shape. Choose squares, circles, or rotated tiles. The tile shape affects how each filled cell is rendered.
  4. Select a mask. Apply a mask to shape the overall composition. The mask restricts the pattern to a defined area, creating a focal form within the 80 × 80 field.
  5. Adjust thresholds. Threshold values control how many cells are filled. Lower thresholds produce sparser patterns; higher thresholds produce denser fields.
  6. Save or record your seed. When you find a composition you like, note the seed value. You can return to it later to reproduce the same artwork exactly.

    🔧 Troubleshooting

    If you encounter an issue while opening or using Mosaic Field, review the suggestions below.

    • The browser shows a blank page. Ensure that you extracted all files from the downloaded folder before opening the HTML file. Missing files can prevent the application from loading.
    • The file does not open. Right-click the HTML file, choose Open with, and select a modern browser. Avoid opening the file in a text editor.
    • Controls do not respond. Refresh the page by pressing F5 or Ctrl + R. If the problem continues, try a different browser.
    • The composition looks different from a previous session. Check the seed value. The same seed always produces the same composition, so a different seed will create a different result.
    • Performance feels slow. Close other browser tabs and applications to free up memory. Ensure your browser is updated to the latest version.

    💡 Tips for Best Results

    • Explore seeds systematically. Try consecutive seed values to see how small changes produce distinct variations.
    • Combine patterns and masks. The mask and pattern interact in interesting ways. Try each pattern with different masks to discover new compositions.
    • Use rotated tiles for texture. Rotated tiles add a woven, handcrafted quality that resembles textile patterns.
    • Take notes. Record seeds and settings for compositions you want to revisit. This turns Mosaic Field into a personal catalogue of designs.
    • Zoom in. Use your browser’s zoom feature (Ctrl + +) to inspect fine details in the grid.
